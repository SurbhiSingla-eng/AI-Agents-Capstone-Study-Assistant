🎓 The Student Study & Research Assistant🎯 Capstone Track: Concierge AgentsThis project implements a multi-agent system designed to streamline the academic research and study process, making it faster, more reliable, and more secure for students and researchers.💡 The Pitch: Problem, Solution, and ValueCategoryDescriptionProblemStudents and researchers waste significant time manually sifting through search results, synthesizing articles, and creating comprehensive study materials (like quizzes). This manual process is inefficient and often leads to context loss between the research and quiz creation phases.SolutionWe built a three-agent, sequential system that automates the entire process: Research $\rightarrow$ Summarization $\rightarrow$ Quiz Generation. The agents pass information seamlessly, ensuring the final quiz is strictly based on the summarized context.Value to UserThis agent reduces the research-to-quiz workflow from hours to minutes, ensures high content integrity, and enables personalized, targeted study sessions, drastically increasing academic productivity.🏗️ Architecture and WorkflowThe system is a sequential Multi-Agent System where specialized agents delegate tasks to each other using the output of the preceding task as their context (memory).Agent Delegation FlowSenior Web Research Analyst: Receives the topic and uses the SerperDevTool to find and compile relevant article snippets.Academic Content Synthesizer: Receives the raw article snippets and synthesizes them into a concise, 400-word academic summary.Experienced Educational Tutor: Receives the summary (as its only memory) and generates a 5-question multiple-choice quiz with answers.✅ Feature Demonstration (The Scoring Criteria)This project successfully implements the key concepts required by the Agents Intensive Capstone:1. Multi-Agent System (Required)The project utilizes three distinct agents with specialized roles (researcher_agent, summarizer_agent, tutor_agent) running in a Process.sequential flow, demonstrating effective task delegation and execution.2. Tools (Required)The Senior Web Research Analyst is equipped with and successfully uses the SerperDevTool (SerperDevTool()). This is a specialized tool that allows the agent to perform real-time, grounded internet searches to fetch current research data.3. Sessions & Memory (Required)We fulfill the context and memory requirement by using the context parameter in the Task definitions.The summarize_task uses the output of the research_task as its context.The quiz_task uses the output of the summarize_task as its context.This linking ensures the Tutor Agent's output (the quiz) is generated strictly from the summarized research—effectively acting as a session-based memory pipeline.🌟 Bonus FeaturesEffective Use of Gemini: All three agents are powered by the gemini-2.5-flash model, utilizing its strong reasoning, summarization, and instruction-following capabilities for high-quality, reliable output.⚙️ Secure Setup and Running InstructionsFollow these steps to run the agent locally.
